# ynison-extension
Расширение для того, чтобы можно было чиллить музычкой
Проект ynison-extension — расширение для совместного/синхронизированного прослушивания музыки (в текущем README это описано как “чиллить музычкой”).

### content/state.js: 
базовое “ядро” — создаёт window.__ymSync, хранит STATE/UI, константы, утилиты (escape, buildInviteLink), работа с профилем/аватаром, debug‑логирование.
### content/clientApi.js: 
клиент для backend API и WebSocket — выбор сервера (domain/lan), fetch-запросы, создание/подключение/пересоздание комнаты, подключение к WS, обработка входящих сообщений и патчинг состояния комнаты/плеера.
### content/playerSyncHostUi.js и content/playerSyncBroadcastBridge.js: 
разделённая логика синхронизации плеера — чтение локального playback (trackId/позиция/пауза), отправка state_update, обработка входящих состояний/команд (play/pause/seek/next), анти-дребезг/TTL, автопопытки “догнать” нужный трек.
### content/roomUi.js: 
UI интеграция в страницу — пункт “Вместе” в сайдбаре, кнопка копирования invite‑ссылки в плеербаре, отрисовка страницы “Совместное прослушивание” (участники, статус, тосты, переключатель API target).
### content/bootstrap.js: 
точка старта — единоразовый bootstrap, чтение roomId из URL/localStorage, установка всех watcher’ов, первичный render(), автосоздание/автоподключение к комнате и открытие страницы /together при необходимости.
